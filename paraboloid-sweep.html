Rotating paraboloid exclusions

Allowed region for 0 along z

Curvature k = √2/2. Let B(n) be the middle region outside both outcome paraboloids:

|r·n| ≤ k (|r|² − (r·n)²).

The state must stay in B(z), but avoid B(n) for every horizontal measurement axis.

Blue points: still allowed.
Red points: excluded by at least one selected horizontal middle region.

The 3D point grid is illustrative, not a proof or a surface-area probability calculation. A finite set can miss small surviving regions. ALL uses the exact analytic union.

3D region (drag to orbit)

The full rotation leaves no allowed region

For any point r = (x,y,z), choose a horizontal unit axis n perpendicular to (x,y). Then r·n = 0, so r belongs to B(n).

Union over horizontal n of B(n) = all of space.
B(z) \ Union B(n) = empty.

Thus the swept middle region fills the entire unit ball shown here, and all of space without the display cutoff. There is no point that stays in an outcome paraboloid for every horizontal axis. Being in one for some axis is a weaker condition and is not sufficient.

The origin is assigned to outcome 0 for every axis. This conclusion is specific to these fixed paraboloid regions with k > 0, not a no-go result for every possible geometric model.
